# Proposed pilot and evaluation

**Pitch scope:** five schools, approximately 4,000 students with access and 12 months. Access is the eligible population, rather than the number of active or retained users.

**Source:** [19-page pitch](presentations/beacon-pitch-19-pages.pdf), especially pages 17–18. The metric definitions below make the pitch's attendance and retention ideas reviewable; they are portfolio documentation, not an approved evaluation protocol.

## What the pilot would test

Can Beacon reduce discovery and first-visit barriers, support verified attendance and encourage repeat participation while remaining manageable for schools and providers?

| Measure | Working definition for evaluation | Why it matters |
| --- | --- | --- |
| Students with access | Students eligible to use the pilot through participating schools | Sets the denominator; does not show engagement |
| First verified visit | A student's first completed, host-verified session in the pilot | Tests movement from discovery into participation |
| Completed sessions | Attendance events verified under the agreed host process | Separates participation from registrations |
| Four-week return | Share of a first-visit cohort with another verified session within 28 days | Tests repeat participation; use only cohorts with a complete observation window |
| Participation breadth | Distribution of verified participation across schools and activity types | Reveals uneven access and activity concentration |
| Delivery effort | Staff and provider time, attendance corrections and support requests | Tests whether the operating model is practical |

No numerical success threshold was established in the supplied files. Schools, youth representatives and evaluation partners would need to agree thresholds, denominators and data access before launch.

## Decisions before scaling

| Risk identified in the pitch | Proposed response |
| --- | --- |
| Low retention | Track four-week return and test the reward design |
| Unproven school willingness to pay | Validate pricing with decision-makers |
| Venue participation | Agree provider responsibilities and backup offers |
| Child safety | Screen hosts, obtain appropriate consent and define moderation |
| Microsoft access | Confirm tenant permissions, eligibility and licensing |
| Existing alternatives | Build trusted provider relationships and validate the connection-layer role |

## Interpretation

More attendance would be evidence of participation, with retention showing whether students return. It would not by itself establish a reduction in offending or prove long-term social impact. Any causal evaluation would need its own design, comparison and ethical review.

No real participant dataset, pilot results or measured prevention outcomes were supplied for this repository.
