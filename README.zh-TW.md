# Beacon｜2026 UQ × Microsoft 黑客松

**🥈 2026 UQ × Microsoft 數位轉型黑客松第二名｜Team 5 團隊成果**

**Microsoft 365 · Power Platform · 青少年參與 · 資料分析 · 科技創新**

Beacon 是我們提出的學校與社區活動平台，協助青少年尋找可信賴的課後活動、驗證實際參與，並透過獎勵與認可鼓勵持續參與。本專案來自昆士蘭大學商學院與 Microsoft 合作舉辦、決賽由 Microsoft 評審的數位轉型黑客松。

這項作品呈現我如何結合研究、資料分析、技術架構與原型設計，把社會問題轉化成具體的數位解決方案。

## 我們想解決的問題

青少年參與課後活動時，可能同時面臨資訊分散、費用與交通、缺乏同伴、安全疑慮及選擇有限等障礙。Beacon 的設計重點，是降低第一次參加的門檻，並讓學生有理由再次參與。

目標使用者為 **12–16 歲學生**。提案規劃以 **5 所學校、約 4,000 名可使用平台的學生、12 個月**進行試點；這些數字是規劃範圍。

## 我們的 solution

| 階段 | 使用者體驗 | 提議採用的技術 |
| --- | --- | --- |
| **發現活動** | 在學校連結的環境中找活動、看清楚資訊、與同儕互動 | Viva Engage、Microsoft Teams |
| **實際參與** | 報名活動、使用 Beacon Pass／QR 碼簽到、確認出席 | Power Apps、Dataverse、Power Automate、Power Pages |
| **持續回訪** | 累積 Torch Points、探索合作獎勵，並發展 Youth Champion 領導機會 | 出席紀錄與獎勵工作流程 |
| **理解參與情況** | 讓學校與合作單位查看彙總參與及回訪資訊 | Power BI，以及提案中的 Purview 治理設計 |

本次黑客松成果包含方案提案、畫面原型、Microsoft 技術架構、利害關係人價值主張、商業模式與試點計畫。提供的資料中沒有可執行應用程式或 Power Platform solution 匯出檔。

## 我的個人貢獻與科技創新能力

我參與了**技術架構、原型、資料分析、研究、方案設計與團隊協作**。第二名是整個團隊共同完成的成果。

| 能力 | 在 Beacon 中的具體呈現 | 對應內容 |
| --- | --- | --- |
| 從研究定義問題 | 把課後參與障礙轉成活動探索、可信賴主辦者與回訪誘因 | [方案設計](docs/solution.md) |
| 整合科技架構 | 將資訊入口、出席驗證、自動化、分析與治理放進同一個 Microsoft 生態系 | [架構說明](docs/architecture.md) |
| 原型與溝通 | 透過 Discover → Participate → Return 畫面，說明完整體驗 | [原型畫面](docs/assets/prototype-journey.png) |
| 資料分析與衡量 | 用背景資料支持問題分析，並規劃出席、首次參與與回訪指標 | [試點與評估](docs/pilot-and-evaluation.md) |
| 技術與商業協作 | 同時考量學生價值、學校管理、社區資源、經費與執行風險 | [商業模式](docs/business-model.md) |

Beacon 的創新重點是把**學校連結的活動探索、可驗證的參與、持續回訪誘因與彙總成效分析**整合成一段完整旅程，讓既有技術與社區資源能共同支持青少年參與。
